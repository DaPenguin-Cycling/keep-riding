Without this file a visitor following an old or mistyped link got GitHub's generic grey 404, with no nav, no branding and no way back into the site except the browser's Back button. `sitemap: false` keeps it out of sitemap.xml — it is a real page to the server but not one to submit to a search engine. It carries no `nav` value, so no navigation item is marked current, which is correct: this is not one of them. The layout supplies the full header and footer, so every route out of here is already on the page; the links below are just the likely ones said plainly. {%- endcomment -%}
